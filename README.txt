# ShopKart - PHP + MySQL E-Commerce

## XAMPP Setup
1. Copy `ShopKart` to `C:\xampp\htdocs\`
2. Start Apache and MySQL from XAMPP.
3. Open `http://localhost/phpmyadmin`
4. Import `database.sql` (or paste it into SQL and run).
5. Open `http://localhost/ShopKart/`

## Default Admin
Email: admin@shopkart.local
Password: admin123

## Notes
- Demo online payment is simulated; no real gateway is used.
- Product images are seeded from public Unsplash image URLs. Admin can also upload JPG/JPEG/PNG/WEBP images.
- Change DB credentials at the top of `index.php` if your XAMPP MySQL root password is not blank.
